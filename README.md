# Articulated Robotic Arm

It's a project for the Graphics Computing course in the Computing Engineering bachelor's program at UNIVASF. It incorporates all the concepts covered in the OpenGL module until now to create an articulated robotic arm with keyboard control.

## Showcase

https://github.com/user-attachments/assets/967cd234-346f-44e5-9aa9-c0f8e7083dee

## Requirements

This project requires the following libraries:

* OpenGL
* Free GLUT
* Make

## How to execute

1. Clone this repository.
2. Execute the `make` commad.
3. Execute the `executable` file.
